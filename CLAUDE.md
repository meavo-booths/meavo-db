## MEAVO release safety

Read [AGENTS.md](AGENTS.md) and [RELEASE_POLICY.md](RELEASE_POLICY.md) before release or deployment work. Work normally on feature branches and through PRs into `staging`. Never push directly to `main`/`staging` or bypass protections. Production actions, including merging/auto-merging/queueing a PR into `main`, need explicit human permission for this repository, the exact action, and the current reviewed PR/head SHA or artifact/configuration scope. Changed content invalidates approval; never infer or manufacture it.
